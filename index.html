Getting it onto the television

Laptop → HDMI. Drag the TV window across and press F for fullscreen.

Chromecast. Chrome menu → Cast → Cast tab, then pick the TV window.

Both windows have to be the same browser on the same machine — that is how they talk to each other. There is no server, so it all works offline.
