    Getting it onto the television

    Laptop → HDMI. Drag the TV window onto the big screen and press F for fullscreen.

    Chromecast. Chrome menu → Cast → Cast tab, then pick the TV window.

    Both windows have to be the same browser on the same machine — that's how they talk to each other. There's no server, so it all works offline.

    Where should the TV open?

    This screen becomes the remote either way. Pick whichever is easier to drag onto the television.
